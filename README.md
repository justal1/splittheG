# Split the G

A Guinness pouring and drinking game for the phone browser. Pour at about 45°, let it settle, top it up, then stop drinking with the dark stout level on the middle of the G.

Single file, WebGL2 (fluid-simulated surge and head). Open `index.html` on a phone over HTTPS for tilt control:

    ./serve.sh      # serves https://<your-LAN-IP>:8766/

Add to Home screen for fullscreen, portrait-locked play.
